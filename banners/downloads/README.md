# downloads

Everything in one place, code-named to match `assets/PHOTO-INDEX.md`. This is
a convenience copy — nothing here is a source of truth, so if a photograph is
recut, recut it in `assets/` and re-copy.

```
photos/       all 19 photographs, full frame, no type and no footer
photo-only/   C1 / P1 / S1 as the banner crops them (1000x1372), no chrome
banners/      C1 / P1 / S1 as finished banners, with type and footer
```

## The chosen set: C1 · P1 · S1

These three are the ones `index.html` renders, so `out/` and
`downloads/banners/` are already this set:

| | Photograph | Wall |
|---|---|---|
| Cupping | `C1-cupping-sage-teal.jpg` | dusty sage-teal |
| Herbal potli | `P1-potli-caramel.jpg` | caramel amber |
| Korean scrub | `S1-scrub-old-rose.jpg` | dusty old rose |

Note that this set predates the autumn palette, so its three walls are *not*
one hue family — they sit at roughly 155°, 39° and 9°, where the autumn three
sit inside 33° of each other. That is a deliberate difference, not a
regression: this is the set with a cool room in it, and the cool-against-warm
play on the cupping frame is the reason that banner reads as well as it does.

The scrim also differs. C1 keeps 0.14 because its sage wall is the lightest of
the three in the tail zone; P1 and S1 run at zero.

## Full frame vs banner crop

`photos/` holds the original 3:4 files. `photo-only/` holds the same pictures
as the banner crops them — 1000 x 1372, which is 0.729, not 0.750. Use
`photos/` when you want the whole frame and `photo-only/` when the crop has to
match the banner exactly.
