DRAG THESE INTO THE FIGMA FILE
https://www.figma.com/design/6TTvUxKDWjXZdpCLsQuQyH

Each filename matches its Figma frame name, so there is nothing to work out:

    1-cupping-therapy.jpg        ->  1 · Cupping therapy
    2-herbal-potli-massage.jpg   ->  2 · Herbal potli massage
    3-korean-body-scrub.jpg      ->  3 · Korean body scrub

HOW
1. In Figma, open a banner in the layers panel and click "Image / photo".
2. Drag the matching file from this folder onto it.
   The rectangle is already 1000 x 1372 and positioned, so it crops as designed.
3. There are 4 colourway rows per service. Fill row A, then copy the image
   fill down the column: select the filled rectangle, Cmd-C, select the
   other three in that column, Cmd-Shift-V (paste properties).

These are the full-resolution originals, 1728 x 2304. Same files as
banners/assets/ — only the names differ, to match the Figma frames.
